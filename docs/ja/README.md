# 人向けドキュメント（日本語）

日本語の人向けガイドはこのツリー（`docs/ja/...`）に置きます。

エージェント向け（`CONTEXT.md`、`docs/agents/`、`docs/adr/`、Cursor rules/skills）は **英語のみ**です。  
英語の人向けガイド: `docs/en/`。

同一ファイルに英語と日本語を混ぜないでください。方針: `docs-language` スキル（`~/.cursor/skills/docs-language`）。
